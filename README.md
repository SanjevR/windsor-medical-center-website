# Windsor Medical Center Website

React + Vite source for the Windsor Medical Center & Med Sleep, LLC public website.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The generated `dist/` directory is deployed to the GoDaddy cPanel `public_html` web root.

## Notes

- Public informational website only.
- Do not use the site to submit PHI or sensitive patient information.
- `node_modules/` and `dist/` are not tracked in Git.
